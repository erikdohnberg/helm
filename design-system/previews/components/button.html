Button

There is no Button component. 39 <button> elements across the app carry 21 distinct className strings, reproduced verbatim below. They resolve to four semantic roles — the variance inside each role is unresolved drift, not intent.

Role 1 — Solid / commit

Save, Continue, primary form submit. 11 uses, 5 spellings.

px-3 py-2 · disabled:opacity-50 · ×5 (as w-full)
px-3 py-1.5 · disabled:opacity-50 + pointer-events-none · ×2
px-3 py-1.5 · no disabled handling · ×2
bg-foreground / text-background instead of primary · ×1
disabled — pending state, label swaps to "Saving…"

Role 2 — Outline / default action

The workhorse. Add team, Cancel, Choose folder, Edit selected. 15 uses, 8 spellings.

border-input · hover:bg-muted · ×6 — the modal spelling
border-border · hover:bg-muted/50 · ×2
same, plus inline-flex items-center · ×3
px-2.5 · no font-medium · transition-colors · ×1
py-2 · text-muted-foreground, not text-foreground · ×1 — the dialog Cancel
disabled — nothing selected
DRIFT — border-input and border-border resolve to the same value in light mode (oklch(0.922 0 0)) but diverge in dark mode (15% vs 10% white). The two spellings are visibly different in dark, identical in light, which is why this drifted unnoticed.

Role 3 — Compact / row action

Inline table actions. The only place a smaller size exists.

px-2 py-1 text-xs · ×3
NOTE — this is the de facto "sm" size, but it is a separate string rather than a size modifier on the outline role. There is no "lg" anywhere in the app.

Role 4 — Ghost / link

Dismiss, sign out, tertiary text actions. 4 uses, 4 spellings.

icon-only · bare `rounded` (4px, off-scale) · ×1
py-3 to match nav height · ×1
link style, no padding · ×1
on-navy variant — hardcoded white alphas · ×1

Role 5 — Marketing CTA (brass)

A separate visual language. Only appears on marketing routes.

Open app hero CTA — rounded-xl, px-7 py-4, text-base, coloured glow, translate on hover
waitlist CTA — rounded-md, px-5 py-2.5, text-sm, no shadow
carousel arrows — all colours hardcoded hex, not tokens · ×2
DRIFT — the two brass CTAs share only their fill. Different radius, padding, size, shadow, and hover mechanic. They are the first and last thing a visitor sees on the landing page.

Focus state

None of the 39 buttons define one. There are zero occurrences of focus-visible in the codebase, so keyboard users get only the UA default — which the reset suppresses on some elements.

as shipped — no ring
what the ring token affords, unused
NOTE — the second button is drawn with a permanent ring purely to show the token. It is not a proposal; the focus treatment is an open design decision. eslint-plugin-jsx-a11y is installed but does not catch this.
