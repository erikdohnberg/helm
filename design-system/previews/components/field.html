Focus treatment is the axis that drifted hardest.

no placeholder:text-muted-foreground · ×3

disabled — no disabled styling defined anywhere; UA default only
DRIFT — three different focus rings (ring-2, ring-1 + border shift, ring-2 + offset-2). All use `focus:` rather than `focus-visible:`, so the ring also fires on mouse click. Inputs are the only elements in Helm with any focus styling at all.

DRIFT — checkbox and radio disagree on everything: border-border vs border-input, no sizing vs h-4 w-4, no focus vs focus:ring-ring. Both rely on the browser's native control rendering underneath. This radio group encodes rule 5 of the product spec ("every new outcome must declare how it enters the quarter"), so it carries more weight than its styling suggests.
