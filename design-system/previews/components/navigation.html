Navigation

Two levels: the app shell top nav and the settings tab strip. Both are real components. Both solve "which item is active?" differently.

Structure is fixed — .cursor/rules/project-constraints.mdc forbids adding, removing, or renaming nav items. Styling is open.

NOTE — the active underline is border-foreground/20, a 20% alpha, so it reads as a faint grey rule rather than a selection marker. Active state leans mostly on the weight change. The real logo is an image asset (black/white swap via dark:hidden); a text placeholder stands in here.

DRIFT — two navigation levels, two unrelated active treatments: the top nav uses a bottom underline, the tabs use a filled folder tab that breaks the border line. Padding differs too (py-3 vs py-2.5, px-3 vs px-4), as does the resting weight (normal vs font-medium).
