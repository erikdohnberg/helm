NOTE — selection uses bg-muted/30, hover uses nothing, and the header uses bg-muted/50. Three alpha steps of the same token doing three jobs, with no hover affordance on rows at all. Actions appear per-row *and* in a toolbar below, so the same operation has two entry points.

No teams yet. Admins can use Add team with a team name and chat user ID (no Helm member required), or add teammates who already belong to the org and use Add details on their row.
