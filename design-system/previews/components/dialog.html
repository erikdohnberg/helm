Behaviour

Not visual, but it constrains what the component can be. Recorded here so the design pass knows what does not exist yet.

Behaviour State
Close on Escape Not implemented — zero keydown handlers in the codebase
Focus trap None
Focus restore on close None
Background scroll lock None
Click-outside to close 1 of 5 — implemented as a full-bleed <button aria-label="Close dialog">
Enter/exit animation None — tailwindcss-animate is installed but unused
role="dialog" aria-modal placement 4 of 5 put it on the full-screen overlay rather than the panel
NOTE — every dialog is labelled with aria-labelledby and a real title id, so the intent was there. The gaps are the things a component would have provided for free.
