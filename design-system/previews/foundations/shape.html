Shape & elevation

Radius derives from a single --radius: 0.625rem token. Elevation does not derive from anything — it is raw Tailwind defaults.

Radius, by actual usage

rounded

var(--radius) → 10px · ×23
rounded-full
9999px · ×15
rounded-xl
Tailwind default 12px · ×12
rounded-2xl
Tailwind default 16px · ×6
DRIFT — six tiers in use, but only three are token-derived. Bare `rounded` (×28, the second most common) is Tailwind's 4px default and bypasses --radius entirely, as do rounded-xl and rounded-2xl. The token scale defines an sm tier — calc(var(--radius) - 4px) — that nothing uses. Roughly: app surfaces use md/lg, marketing uses xl/2xl.

NOTE — spacing is the most internally consistent part of the system: a clean 2/3/4/6 ladder with almost no exceptions. Worth preserving. The tone rules ask for "generous spacing"; the app currently sits tighter than the marketing pages, which use py-[104px] section rhythm.
