Principles

Verbatim from lib/design/README.md. These predate this kit and are the constraint the visual work should be judged against — not a summary written for the handoff.

UX tone rules

  • calm
  • editorial
  • minimal
  • generous spacing
  • no dashboard density
  • no bright status colors
  • no gamified scoring
  • muted chips only
  • external links show external-link icon

What Helm is

A strategic alignment layer — not a task manager, sprint planner, roadmap tool, or OKR platform.

The core artifact is the Outcome Charter. Anchored outcomes represent the official direction of a quarter, and new priorities must not enter the system silently.

Helm's job is to surface one question: "What stops?"

Where the rules bite

"no bright status colors" vs. the token set

The inherited shadcn preset ships five saturated chart colours. They are unused today. Drift severity, outcome state, and replacement relationships all need visual encoding — and none of them may reach for a red/amber/green vocabulary.

Anchored Replaced Additive — all states currently render identically
"muted chips only"

Honoured — Chip has no variant API and only ever renders bg-muted. The constraint is currently enforced by the component having no other options, not by a decision. If chips gain variants, this is the rule they must stay inside.

"editorial" vs. two visual languages

The marketing surface is editorial — navy, brass, generous vertical rhythm, a compass-rose motif, real typographic care. The app surface is neutral shadcn zinc. They share a repo and almost nothing else. Whether these converge is the largest open question in this handoff.

"no dashboard density" / "generous spacing"

The app is built on text-sm with p-3 table cells and a 2/3/4/6 spacing ladder — closer to dense-admin than to the marketing pages' py-[104px] rhythm. This is the rule the app diverges from most.

NOTE — these rules are prose in a README today. Nothing enforces them. A goal of the design pass is to push as many as possible into the component APIs, where they hold by construction.
